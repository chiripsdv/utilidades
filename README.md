# Utilidades

Herramientas web simples, listas para usar desde el navegador.

## Generador de CV

Formulario para llenar tus datos y descargar un CV elegante en PDF tamaño carta.

**Usar:** https://chiripsdv.github.io/utilidades/generador-cv/

- Vista previa en vivo mientras escribís.
- Experiencia, educación, cursos, habilidades e idiomas sin límite de cantidad.
- Foto opcional, cuatro colores de acento.
- Los datos se guardan solo en tu navegador; no se envían a ningún servidor.
